Discover bundled workflow guides with `loadouts agents`. The offline guides cover exploring a setup, applying selections and restoring a checkout, diagnosing problems, and preparing a catalog contribution. Existing `loadouts explore` invocations still print the exploration guide. Root help lists the guides in the command table. Rerun `loadouts setup` to refresh the workflow pointer in each selected agent’s `LOADOUTS.md`.

Discover bundled workflow guides with `loadouts agents`. The offline guides cover exploring a setup, applying selections and restoring a checkout, diagnosing problems, and preparing a catalog contribution. Use `loadouts agents explore` in place of the removed top-level `loadouts explore` command. `loadouts doctor` checks the machine configuration, guide imports and workflow guidance after setup, including outside a project. Root help lists the guides in the command table. Rerun `loadouts setup` to refresh the workflow pointer in each selected agent’s `LOADOUTS.md`.
